THE LOVECHANNELS — SOURCE FILES

1. Install Node.js 24, then run npm ci in this folder.
2. Open START-WEBSITE.cmd, or run node server/index.mjs.
3. Visit http://127.0.0.1:4173/?look=blue-white&font=inter

Local development uses its own SQLite database and never changes hosted records.
Set ADMIN_EMAIL and ADMIN_PASSWORD before the first local start to choose your
local administrator. Otherwise a generated local password is printed once.
Use /#/member and /#/admin with an ordinary authenticated account.

Live site: https://lovechannels-rebuilt.vercel.app
Deployment and provider setup: README-HOSTING.md
Security details and remaining configuration: SECURITY.md
Secrets and live database credentials are excluded from this package.
